# Using Papo TUI

This guide explains how to run Papo TUI, use each of its features and solve
common problems. To install the program first, see the
[installation guide](installation.md).

The guides name buttons and notices as they appear in the Portuguese interface,
followed by their meaning in English, which is also what the English interface
shows.
