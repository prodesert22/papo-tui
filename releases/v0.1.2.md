# Papo TUI 0.1.2

This release adds Shift+Enter for multiline messages in supported terminals.

## Keyboard controls

- Shift+Enter inserts a new line without sending the message. Enter continues
  to send, and Ctrl+N remains available when the terminal cannot distinguish
  Shift+Enter from Enter.
- The shortcut supports the numeric keypad and CapsLock/NumLock modifiers.
  Numeric keypad navigation and editing shortcuts remain available.
- Shift+Enter does not submit the sign-in form. Supported terminals restore
  their previous keyboard mode when the application exits; other terminals
  keep their existing mode.

The release uses the existing service API and adds no backend requirements.
See the [usage guide](../docs/usage.md) for application controls.
