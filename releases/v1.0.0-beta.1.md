# Papo TUI 1.0.0-beta.1

This is a **pre-release** of Papo TUI 1.0.0 for testing. It contains every
change since [0.5.0](v0.5.0.md) that will ship in 1.0.0, but some of them have
not yet been verified on every system. Keep using 0.5.0 if you need a stable
version, and report problems in the
[issue tracker](https://github.com/prodesert22/papo-tui/issues). The complete
notes come with the final 1.0.0 release.

This beta ships the Linux packages for **x86_64** and **ARM64**, the
**Windows x86_64** installer and portable ZIP, the **Android / Termux**
package and the **source archive**. Windows on ARM64 is not part of this
pre-release; see [Not in this pre-release](#not-in-this-pre-release). Each
package was built in a clean environment and checked by installing it and
starting the application.

## Highlights

- **Voice calls** with microphone and audio toggles below your name, Audio
  settings for devices and volumes, and optional push-to-talk.
- **Your profile and password on each server**: nickname, status, description,
  avatar and banner in **Ctrl+S → Perfil**, and a password change in **Conta**.
- **Server settings** for administrators: roles, channels, members, emojis,
  webhooks and the audit log.
- **English interface**, chosen in **Ctrl+S → Aparência → Idioma**, and a light
  theme.
- **Every server you were signed in to reopens as a tab**, and a server that
  stops answering keeps its tab marked **(offline)** until it is back.
- **Audio attachments, SVG images, GIF search** (the **[GIF]** source of the
  emoji picker) and GIF link previews that play in place.
- **Ctrl+K** jumps to any conversation of any server; drafts and replies
  survive closing the application.
- **Clicking a desktop notification** opens its conversation and brings the
  terminal to the front, now also on Windows.
- **Linux console (TTY)**: readable focus highlights, symbols the console fonts
  can draw, and emojis shown by name.
- Server addresses can be typed without `https://`.
- **Message attachments** now use file cards with a download button, a
  background download with progress, and a chooser when a message has several
  files.
- **Search, pins and notifications** keep their filters, follow the newest
  message correctly, and mark a conversation read only when its latest message
  is visible.
- **Smoother history navigation**: recent conversations are kept, consecutive
  messages from the same author are separated after an hour, and text can be
  selected with the mouse.

## Please test

- Voice calls between two accounts.
- The **Linux console** (Ctrl+Alt+F3): focus colors, buttons and the emoji
  picker.
- Each Linux package on its own distribution, especially the Flatpak bundle on
  RHEL and the AppImage on distributions other than Ubuntu.
- The **ARM64** packages on real ARM64 computers; they were checked under
  emulation only.
- On **Windows**, the installer in a user account whose folder has accented
  characters, and Papo TUI opened from Git Bash or WezTerm as well as from
  Windows Terminal.
- The **Termux** package on an Android device.

## Downloads

Choose your system and architecture: **x86_64** for 64-bit Intel/AMD computers
or **ARM64** (AArch64). Every package has the same version and
`papo-tui --version` prints **papo-tui 1.0.0-beta.1**. Package managers order
this version before the final 1.0.0, so upgrading to 1.0.0 later works as
usual.

- **Portable folder**: extract the archive anywhere and run
  `papo-tui-1.0.0-beta.1/bin/papo-tui`; keep the whole folder together. It
  needs glibc 2.39 or newer and the system's CA certificates, terminal
  database and font configuration, which most distributions install by
  default.
- **Windows**: these packages also include a fix made after this tag
  ([cfa6c76](https://github.com/prodesert22/papo-tui/commit/cfa6c76)). Without
  it, Papo TUI exits at startup with "ncurses: cannot initialize terminal
  type" when it is installed in a folder with accented characters, such as a
  user folder like `C:\Users\João`, and opened from a terminal that sets
  `TERM`, such as Git Bash or WezTerm.
- **Android / Termux**: in Termux, run
  `apt install ./papo-tui-1.0.0-beta.1-termux-aarch64.deb`. The package is built
  from this tag with two build fixes made after it
  ([effd503](https://github.com/prodesert22/papo-tui/commit/effd503)), which
  the recipe in `dist/termux/` applies. It has no voice calls, because the
  WebRTC stack is not published for Android.
- **Source code**: `papo-tui-1.0.0-beta.1-source.tar.gz` contains every file
  needed to build the application; follow
  [BUILD.md](https://github.com/prodesert22/papo-tui/blob/v1.0.0-beta.1/BUILD.md).
- **Checksums**: `SHA256SUMS` lists every file of the release. In the download
  folder, run `sha256sum --check --ignore-missing SHA256SUMS`.

See the [installation guide](https://github.com/prodesert22/papo-tui/blob/v1.0.0-beta.1/docs/installation.md)
for the commands of each package.

## Not in this pre-release

- **Windows 11 on ARM64**: the installer and portable ZIP are planned for the
  final 1.0.0 release. Until then, build from the source archive.
