# Papo TUI 0.6.0-beta.1

This is a **pre-release** of Papo TUI 0.6.0 for testing. It contains every
change since [0.5.0](v0.5.0.md) that will ship in 0.6.0, but some of them have
not yet been verified on every system. Keep using 0.5.0 if you need a stable
version, and report problems in the
[issue tracker](https://github.com/prodesert22/papo-tui/issues). The complete
notes come with the final 0.6.0 release.

## Highlights

- **Voice calls** with microphone and audio toggles below your name, Audio
  settings for devices and volumes, and optional push-to-talk.
- **Your profile and password on each server**: nickname, status, description,
  avatar and banner in **Ctrl+S → Perfil**, and a password change in **Conta**.
- **Server settings** for administrators: roles, channels, members, emojis,
  webhooks and the audit log.
- **English interface**, chosen in **Ctrl+S → Aparência → Idioma**, and a light
  theme.
- **Every server you were signed in to reopens as a tab**, and a server that
  stops answering keeps its tab marked **(offline)** until it is back.
- **Audio attachments, SVG images, GIF search** (the **[GIF]** source of the
  emoji picker) and GIF link previews that play in place.
- **Ctrl+K** jumps to any conversation of any server; drafts and replies
  survive closing the application.
- **Clicking a desktop notification** opens its conversation and brings the
  terminal to the front, now also on Windows.
- **Linux console (TTY)**: readable focus highlights, symbols the console fonts
  can draw, and emojis shown by name.
- Server addresses can be typed without `https://`.

## Please test

- On **Windows**: click a desktop notification, or the icon it adds to the
  notification area, with the terminal behind other windows or minimized, in
  both Windows Terminal and the classic console.
- On the **Linux console** (Ctrl+Alt+F3): focus colors, buttons and the emoji
  picker.
- Voice calls between two accounts.

## Downloads

Choose your system and architecture: **x86_64** for 64-bit Intel/AMD computers
or **ARM64** (AArch64). Every package of this release has the same code and
`papo-tui --version` prints **papo-tui 0.6.0-beta.1**. Package managers order
this version before the final 0.6.0, so upgrading to 0.6.0 later works as usual.

- **Android / Termux (ARM64)**: this pre-release has no prebuilt Termux
  package. Build it with the official Termux package builder and the recipe in
  `dist/termux/build.sh`, as described in
  [BUILD.md](https://github.com/prodesert22/papo-tui/blob/v0.6.0-beta.1/BUILD.md#termux-android-arm64).
  It has no voice calls, because the WebRTC stack is not published for Android.
- **Source code**: `papo-tui-0.6.0-beta.1-source.tar.gz`. Packages that bundle
  third-party libraries come with their sources in the matching
  `-dependency-sources.tar.gz` or `-sources.tar.gz` archive.
- **Checksums**: `SHA256SUMS` lists every file of the release. In the download
  folder, run `sha256sum --check --ignore-missing SHA256SUMS`.

See the [installation guide](https://github.com/prodesert22/papo-tui/blob/v0.6.0-beta.1/docs/installation.md)
for the commands of each package.
