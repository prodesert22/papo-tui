# Papo TUI 0.1.1

This release adds faster emoji entry and improves the emoji picker.

## Emoji suggestions and picker

- Type `:` in the message editor to open filtered suggestions for Unicode and
  server emojis. Suggestions are ranked by recent use and usage is saved for
  each account and server.
- The F4 emoji picker shows larger 32×32 previews with emoji names and supports
  keyboard navigation between search, emoji sources and results.
- Opening the picker keeps chat images visible outside the picker area.

The release uses the existing service API and adds no backend requirements.
See the [usage guide](../docs/usage.md) for application controls.
