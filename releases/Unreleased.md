- Reopening the member list with **Ctrl+U** no longer empties it and downloads every member again: within a minute it shows the members already loaded, and a later reopening or **Ctrl+R** checks the list in the background while it stays on screen. Each new page of members also no longer takes longer as the list grows.
- `papo-tui --help` now describes what the application does without options, each option, the `PAPO_LANGUAGE` and `CURL_CA_BUNDLE` environment variables, where profiles, sessions and drafts are kept and a link to the user guide. It no longer lists keyboard shortcuts, which stay in the in-app help, and its lines fit 80 columns. In a terminal it colors its headings, options and links; set `NO_COLOR` for plain text, which is also what a file or pipe receives.
