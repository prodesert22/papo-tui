# Papo TUI 1.0.0-beta.2

This is the second **pre-release** of Papo TUI 1.0.0 for testing. It contains
every change since [0.5.0](v0.5.0.md) that will ship in 1.0.0, but some of them
have not yet been verified on every system. Keep using 0.5.0 if you need a
stable version, and report problems in the
[issue tracker](https://github.com/prodesert22/papo-tui/issues). The complete
notes come with the final 1.0.0 release.

It ships the Linux packages for **x86_64** and **ARM64**, the **Windows x86_64**
installer and portable ZIP, the **Android / Termux** package and the **source
archive**, and every file is **signed** (see
[Verifying the downloads](#verifying-the-downloads)). Windows on ARM64 is not
part of this pre-release.

## Changes since 1.0.0-beta.1

- Signing in works again for an account where the server detected reuse of an
  old session. Before, every sign-in failed with "A sessão foi revogada pelo
  servidor" even with the right password. Papo TUI now signs in and shows
  **Sessão reutilizada · troque a senha** (Session reused · change the
  password) in the status bar until the password is changed in
  **Ctrl+S → Conta**.
- On Windows, Papo TUI no longer exits at startup with "ncurses: cannot
  initialize terminal type" when it is installed in a folder with accented
  characters, such as `C:\Users\João`, and opened from a terminal that sets
  `TERM`, such as Git Bash or WezTerm. The 1.0.0-beta.1 Windows packages
  already carried this fix; it is now part of the source.
- The Termux package builds from the unmodified source.

## Highlights

- **Voice calls** with microphone and audio toggles below your name, Audio
  settings for devices and volumes, and optional push-to-talk.
- **Your profile and password on each server**: nickname, status, description,
  avatar and banner in **Ctrl+S → Perfil**, and a password change in **Conta**.
- **Server settings** for administrators: roles, channels, members, emojis,
  webhooks and the audit log.
- **English interface**, chosen in **Ctrl+S → Aparência → Idioma**, and a light
  theme.
- **Every server you were signed in to reopens as a tab**, and a server that
  stops answering keeps its tab marked **(offline)** until it is back.
- **Audio attachments, SVG images, GIF search** (the **[GIF]** source of the
  emoji picker) and GIF link previews that play in place.
- **Ctrl+K** jumps to any conversation of any server; drafts and replies
  survive closing the application.
- **Clicking a desktop notification** opens its conversation and brings the
  terminal to the front, now also on Windows.
- **Linux console (TTY)**: readable focus highlights, symbols the console fonts
  can draw, and emojis shown by name.
- Server addresses can be typed without `https://`.
- **Message attachments** now use file cards with a download button, a
  background download with progress, and a chooser when a message has several
  files.
- **Search, pins and notifications** keep their filters, follow the newest
  message correctly, and mark a conversation read only when its latest message
  is visible.
- **Smoother history navigation**: recent conversations are kept, consecutive
  messages from the same author are separated after an hour, and text can be
  selected with the mouse.

- **Portable folder**: extract the archive anywhere and run
  `papo-tui-1.0.0-beta.2/bin/papo-tui`; keep the whole folder together. It needs
  glibc 2.39 or newer and the system's CA certificates, terminal database and
  font configuration, which most distributions install by default.

  `apt install ./papo-tui-1.0.0-beta.2-termux-aarch64.deb`. It has no voice calls,

- **Source code**: `papo-tui-1.0.0-beta.2-source.tar.gz` contains every file needed to

## Verifying the downloads

Every file is signed with the OpenPGP key
**AA09 D90E 1547 7426 DAFD  F098 30F8 5714 E332 3D6B**, published with the release as `papo-tui-signing-key.asc`. Import it
once and check that the fingerprint matches:

```sh
gpg --import papo-tui-signing-key.asc
gpg --fingerprint 30F85714E3323D6B
```

- **Any file**: `SHA256SUMS` lists every file and `SHA256SUMS.asc` signs it.
  In the download folder run
  `gpg --verify SHA256SUMS.asc SHA256SUMS && sha256sum --check --ignore-missing SHA256SUMS`.
  Each file also has its own `.asc` signature: `gpg --verify FILE.asc FILE`.
- **DEB** packages carry their signature inside: `dpkg-sig --verify FILE.deb`.
- **RPM** packages carry their signature inside:
  `sudo rpm --import papo-tui-signing-key.asc` and then `rpm -K FILE.rpm`.
- **Arch Linux** packages have a detached `.sig`, as pacman expects:
  `gpg --verify FILE.pkg.tar.zst.sig FILE.pkg.tar.zst`.
- **Flatpak** bundles are signed inside and carry the key, so
  `flatpak install` checks them.
- **Windows**: the installer and ZIP have no Authenticode signature, so
  Windows may warn that the publisher is unknown; verify them with their
  `.asc` signatures instead.

- **Windows 11 on ARM64**: the installer and portable ZIP are planned for the
